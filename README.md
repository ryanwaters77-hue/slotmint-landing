# Slotmint Landing Page

Premium, highly interactive digital agency landing page built for a business on Polsia.

**Target URL:** [slotmint-5polsia.io](https://slotmint-5polsia.io)

## Features

- **Motion Graphics**: Framer Motion scroll-driven hero (clip-path circle expand from 0% to 150%), infinite client logo ticker, whileInView section entrances, expanding flex work gallery with smooth easing.
- **Lit-up Buttons**: Fully rounded, scale on hover/active, neon glow shadows using `#00f0ff` (cyan) and `#b026ff` (purple).
- **Design System**: Deep Midnight Blue `#0c1128`, Outfit font (300-900), glassmorphism (`bg-white/5`, `backdrop-blur`, `border-white/10`), precise tracking and leading.
- **Sections**: Navbar (pill glass), Hero (300vh sticky), Clients ticker, Services 2x2 cards, Work expanding gallery, About split, Footer massive CTA.
- **Tech Stack**: React 19 + TypeScript + Vite + Tailwind CSS v4 + Framer Motion + Lucide React.

## Run Locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Deploy

Build with `npm run build` and deploy the `dist/` folder to any static host, or connect the repo to Vercel/Netlify/Cloudflare Pages for automatic deploys.
